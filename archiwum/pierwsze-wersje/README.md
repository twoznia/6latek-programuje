# Pierwsze wersje (archiwum)

Prototypy kart z pierwszej rozmowy, zanim treść trafiła do plików Markdown w `poziomy/`. Zostawione dla porównania. Aktualne materiały do druku są w [`druk/`](../../druk/).

- `poziom-1-robot-i-programista.pdf`: pierwsza wersja poziomu 1 (pionowe karty, liczby kładzione za poleceniem).
- `poziom-1-v2-karty-z-okienkiem.pdf`: wersja 2, poziome karty z okienkiem na liczbę. Ten projekt kart został wybrany i jest używany dalej.
- `gen.py`, `gen2.py`, `head.html`, `intro.html`, `outro.html`, `v2.css`: skrypty i szablony, z których powstały te PDF-y.
- `pdf.js`, `pdf2.js`: zamiana HTML na PDF przez Playwright.

Dziś zamiast nich używa się `narzedzia/drukuj.py`.
